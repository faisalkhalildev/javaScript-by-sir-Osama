A structured JavaScript practice repository covering fundamentals, DOM projects, object-oriented programming, asynchronous JavaScript, ES6+ features, and problem-solving exercises.

## Overview

This repository documents my JavaScript learning journey through practical examples and mini projects.  
The goal is to move beyond theory and build hands-on understanding of how JavaScript works in real browser-based applications.

The code in this repository includes:

- core JavaScript fundamentals
- array methods and data transformation
- DOM selection, events, and form handling
- local storage and browser-based state
- object-oriented programming with classes and inheritance
- asynchronous JavaScript with `fetch`, Promises, and `async/await`
- modern ES6+ features such as destructuring, rest/spread, optional chaining, sets, maps, and generators
